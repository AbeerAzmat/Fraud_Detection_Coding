
# Data Mining with Python

This work is a combination of my efforts along with my team members.  
This repository contains projects and analyses related to data mining using Python, including:

- **Iris Classification and Clustering:** Using Naive Bayes and KMeans clustering on the Iris dataset.
- **Online Payment Fraud Detection:** Data analysis and machine learning modeling for fraud detection.
- **Regression, Correlation, PCA, and Network Mining:** Scripts for regression analysis, correlation heatmaps, dimensionality reduction, and network graph mining.

## Dataset

This project uses the following datasets:

- **Iris dataset:** included as `iris.csv` or loaded via seaborn/sklearn.
- **Fraud detection dataset:** `new_data.csv` (transaction data).
- **Les Miserables network graph:** `lesmiserables.gml`.

## Installation

Install required Python packages via:

pip install -r requirements.txt


## Usage

- Run Jupyter notebooks in `notebooks/` for interactive analysis.
- Use Python scripts in `src/` for modular execution.
